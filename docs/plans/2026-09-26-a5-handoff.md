## 3. Lessons from this session (also in memory)

- **Remote builders see only their own branch.**
  - Never ask one to merge main or read another branch; paste the code into the plan.
  - When stacking rounds, bind on `origin/main` **after** the previous PR merged.
    Otherwise it lacks the earlier round (R4a halted twice).
  - A branch built on a pre-squash branch conflicts with main. Cherry-pick its own
    commits onto main; that applied cleanly twice.
- **contabo's check-comments can pass without checking anything.** Always rerun
  `sh scripts/check-comments.sh` locally. It caught "§" three times today.
- **The repo requires a branch to be up to date before merge.** Loop on
  `gh pr update-branch` when the state is BEHIND. `gh pr checks --watch` can return
  early, so poll until nothing is IN_PROGRESS.
- **Real smoke rounds find what goldens don't:** the marker ordering (#613) and the
  sweep race (#614). Always run a real round after a release.
- **Use sqlite `VACUUM INTO` for backups** while the daemon runs; `.backup` livelocks.
- **Mutation-test every plan.** A mutation that cannot fail means the plan is wrong. It
  happened once today; the status actor fallback needed a stronger test.
