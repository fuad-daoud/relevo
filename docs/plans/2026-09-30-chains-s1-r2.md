## Pinned schema (016_chains.sql)

Follow `internal/db/migrations/README.md` and the dialect of `014_installation_origin.sql`: add-only,
idempotent DDL, RFC3339 millis, no triggers/views/FTS/virtual tables/RETURNING.

```sql
CREATE TABLE IF NOT EXISTS chains (
    id TEXT PRIMARY KEY,
    origin TEXT NOT NULL DEFAULT '',
    owner TEXT NOT NULL DEFAULT '',
    name TEXT NOT NULL,
    status TEXT NOT NULL,
    reason TEXT NOT NULL DEFAULT '',
    phase TEXT NOT NULL,
    step TEXT NOT NULL,
    plan INTEGER NOT NULL,
    plans INTEGER NOT NULL,
    plan_paths TEXT NOT NULL,            -- JSON array of the stored plan copies
    corrections INTEGER NOT NULL DEFAULT 0,
    awaiting_member TEXT NOT NULL DEFAULT '',
    awaiting_round INTEGER NOT NULL DEFAULT 0,
    settings TEXT NOT NULL DEFAULT '{}', -- JSON of the resolved settings
    builder TEXT NOT NULL,
    reviewer TEXT NOT NULL DEFAULT '',
    planner TEXT NOT NULL DEFAULT '',
    security TEXT NOT NULL DEFAULT '',
    base TEXT NOT NULL DEFAULT '',
    branch TEXT NOT NULL DEFAULT '',
    repo TEXT NOT NULL DEFAULT '',
    worktree TEXT NOT NULL DEFAULT '',
    feature TEXT NOT NULL DEFAULT '',
    ticket TEXT NOT NULL DEFAULT '',
    server TEXT NOT NULL DEFAULT '',     -- reserved for slice 3
    mastermind_id TEXT NOT NULL DEFAULT '',
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
CREATE UNIQUE INDEX IF NOT EXISTS chains_origin_owner_name_uidx ON chains(origin, owner, name);
CREATE INDEX IF NOT EXISTS chains_owner_builder_idx  ON chains(owner, builder);
CREATE INDEX IF NOT EXISTS chains_owner_reviewer_idx ON chains(owner, reviewer);
CREATE INDEX IF NOT EXISTS chains_owner_planner_idx  ON chains(owner, planner);
CREATE INDEX IF NOT EXISTS chains_owner_security_idx ON chains(owner, security);

CREATE TABLE IF NOT EXISTS chain_event (
    chain_id TEXT NOT NULL REFERENCES chains(id) ON DELETE CASCADE,
    seq INTEGER NOT NULL,
    ts TEXT NOT NULL,
    phase TEXT NOT NULL,
    step TEXT NOT NULL,
    member TEXT NOT NULL,
    round INTEGER NOT NULL,
    event TEXT NOT NULL,   -- JSON: {"kind":"builder_closed","outcome":"done","gate":"green"}
    action TEXT NOT NULL,  -- JSON: {"kind":"send","member":"x-rev","seed":"reviewer"}
    reason TEXT NOT NULL DEFAULT '',
    PRIMARY KEY (chain_id, seq)
);
```

The four member columns are the membership record; `ChainGetByMember` is a single query with
`(builder = ? OR reviewer = ? OR planner = ? OR security = ?)` plus the origin/owner scope, and the
per-column indexes back it. `event`/`action` stay JSON strings so slice 2/3 add fields without a
migration.

## Exact shapes

`internal/db/chain.go`:

```go
type ChainRow struct {
    ID, Origin, Owner, Name, Status, Reason, Phase, Step string
    Plan, Plans, Corrections int
    PlanPathsJSON, SettingsJSON []byte
    AwaitingMember string; AwaitingRound int
    Builder, Reviewer, Planner, Security string
    Base, Branch, Repo, Worktree, Feature, Ticket, Server, MasterMindID string
    CreatedAt, UpdatedAt time.Time
}
type ChainEventRow struct {
    ChainID string; Seq int; TS time.Time
    Phase, Step, Member string; Round int
    Event, Action, Reason string
}
func (c ChainRow) Valid() error // id/name/status/phase/step non-empty; plans >= 1; plan in [1,plans]; ErrInvalid otherwise

// *DB reads (no transaction needed), owner-scoped on the handle's origin:
func (d *DB) ChainGet(owner, name string) (ChainRow, bool, error)
func (d *DB) ChainGetByMember(owner, member string) (ChainRow, bool, error)
func (d *DB) ChainList(owner string) ([]ChainRow, error)
func (d *DB) ChainEvents(id string) ([]ChainEventRow, error)

// *Tx writes (callers hold the state lock):
func (t *Tx) ChainPut(c ChainRow) error
func (t *Tx) ChainDelete(owner, name string) error
func (t *Tx) ChainEventAppend(id string, e ChainEventRow) error // seq = COALESCE(MAX(seq),0)+1 in the INSERT ... SELECT
```

`internal/store/chain.go` (mirrors the `Load`/`List` + `Tx` pairs at
`internal/store/lifecycle.go:19-37,126-148`; owner is the store's own):

```go
func (s *Store) Chain(name string) (db.ChainRow, error)          // ErrNotFound when absent
func (s *Store) ChainByMember(member string) (db.ChainRow, error)
func (s *Store) Chains() ([]db.ChainRow, error)
func (s *Store) ChainEvents(name string) ([]db.ChainEventRow, error)
func (t *Tx) Chain(name string) (db.ChainRow, error)
func (t *Tx) ChainByMember(member string) (db.ChainRow, error)
func (t *Tx) Chains() ([]db.ChainRow, error)
func (t *Tx) ChainPut(c db.ChainRow) error
func (t *Tx) ChainEvents(name string) ([]db.ChainEventRow, error)
func (t *Tx) ChainEventAppend(name string, e db.ChainEventRow) error
func (t *Tx) CreateChain(c db.ChainRow, members []Binding) error     // one db.Tx: ChainPut + every member's RecordPut
func (t *Tx) ChainSaveWithEvent(c db.ChainRow, e db.ChainEventRow) error // one db.Tx: ChainPut + ChainEventAppend
```

`CreateChain` runs `s.prepareSave` (internal/store/lifecycle.go:189) per member, then one
`d.Tx(func(dtx *db.Tx) error { for each rec: dtx.RecordPut(rec); dtx.ChainPut(c) })`: a failing member
leaves no chain row and no member row. `ChainSaveWithEvent` is the design's "the event, the new state
and the trace row are written in one transaction".

## Halt conditions

- If `internal/db/migrations/016_chains.sql` already exists, halt and report.
- If `db.RecordPut` is not callable from the same `*db.Tx` as a new `ChainPut` (see
  `internal/db/record.go:229`, `internal/db/db.go:290`), halt: the all-or-none create needs it.
- If the store's owner/origin plumbing cannot scope the new table the way `binding_record` is scoped
  (`internal/db/record.go:52-58`, `internal/store/lifecycle.go:337-353`), halt and report.
