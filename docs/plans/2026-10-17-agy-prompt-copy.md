# Plan: fix #1258 -- agy at read/edit cannot read its own round prompt

Saved verbatim as `docs/plans/2026-10-17-agy-prompt-copy.md` in the last step.

## Findings (checked against the code, not only the seed)

- agy's print form is `--add-dir <DirPlaceholder> --add-dir <OutputDirPlaceholder>` (`internal/harness/harness.go` ~325). `agy` tiers are `read` -> `--mode plan`, `edit` -> `--mode accept-edits`, `yolo` -> `--dangerously-skip-permissions` (`internal/harness/tier.go` 75-85); `harness` adds no relevo permission flag. The copy is wanted only at agy + `read`/`edit`.
- Every handoff template (`builderPrompt`, `readerPrompt`, `chainReaderPrompt`, `internal/relevo/send.go` 45-125) carries exactly one line `Read: <path>\n`, rendered by `composePrompt` / `composeChainReaderPrompt` / `roundPrompt` (send.go ~911-961). Nothing else in those templates names the prompt path.
- **The candidate and tier are not final at compose time.** `repair.go:149` and `chain_send.go:82` compose the text BEFORE `repickStale`, and `send.go:361` (preflight) composes before `opts.Tier` has been put into `b.RoundTier` (that happens at send.go:579). A compose-time decision could therefore name the copy for a candidate that is not the one launched, or the original for one that is. So the decision is made at launch, where the candidate and tier are final, not at compose.
- Every real launch goes through `startRound` (`headless.go:~268-293`, the only caller of `HeadlessLaunch` for a round) or `resumeRound` (`headless.go:~440-488`), and both end in `startProcess` (`headless.go:325`), which already calls `EnsureOutDir` before every spawn. The callers of those two, which all pass the composed text: `Send` (send.go ~590-640), `Admit` (`queue.go:42`, the served and deferred path), `chain_send.go:82`, `repair.go:149`, `switch.go:378` (mid-round switch and rotation), `headless.go:1141` (relaunch/resume after a daemon restart). A served (server-side) launch is the same `startRound` on the server's store. Hooking `startRound`/`resumeRound` covers all of them.
- The read-only paths that build an argv without launching: `sendPreflight` (send.go ~425-440, dry run) and `bind.go:822` (render-only, prompt `""`). `consult/verify.go:287` and `availability/probe.go` use inline prompts with no round prompt file; they are untouched.
- **Ingest of `out/`** (`internal/store/roundwalk.go` `diskFiles`/`walkOutDir`/`walkOutEntries`, `seal.go` `SealRound`):
  - A non-dot `out/NNN-prompt.md` is a flat round file named `NNN-prompt.md`. `diskFiles` lets the `out/` entry win over the flat original of the same name, so `SealRound` would seal the copy's bytes under the original's key and `sealRemove` would remove only the copy; the flat original would be left behind on disk forever, and the DONE cleanup (`daemon.go:~669`, "out/ is empty") would never empty the directory. It also appears in `RoundFiles`/`RoundsOnDisk`. Rejected: a copy under that name is confusable with the record.
  - `walkOutEntries` and `walkOutArtifact` skip any entry whose name starts with `.`, `migratableRunnerOutput` requires the `NNN-` prefix, and `removeEmptyRoundDirs` skips dot entries. A dot-named file is therefore never walked, listed, sealed, forked or migrated.
  - **Decision: the copy is `<binding>/out/.NNN-prompt.md`** (dot-file, the original's base name behind a dot; the round number keeps rounds apart). Hazard that follows: a dot-file is never sealed, so relevo must remove it itself, or `out/` never empties on DONE. Removal is added to `SealRound` (step 3). A leftover for a round that never seals is removed with the binding directory on unbind (unchanged behaviour, assert in a test if the unbind path is a pure store function).
  - Whether agy's own `read_file` accepts a dot-named path inside an add-dir is unverified; step 9 (real binary) decides. If agy refuses a dot-file, halt and report; the fallback is a dot-directory `out/.prompts/NNN-prompt.md` (also skipped by the walk), not a non-dot name.
- Writes into `out/` must go through `os.Root` (`Store.OutRoot`, `confined.go`): `out/` is runner-writable, so a symlink planted at the copy's path must not redirect a relevo write. Use `Root.OpenFile` with `O_NOFOLLOW`-equivalent handling the way the reader-output writer does (`summary.go` `readerOutputRoot`, ~180-210): write a temp name then `Root.Rename` over the target, or remove-then-create-excl; a non-regular existing entry is replaced only if `Root.Remove` succeeds, never followed. File mode 0644. `out/` is created by `EnsureOutDir` (tenant chown applied there); the copy needs no chown of its own beyond the file being world-readable, same as the staged plan (`stage.go` 0o644).
- The copy is rewritten at every launch from the original (`Store.ReadFile(PromptPath)`), so a runner that edited it, a relaunch, a resume, a rotation or a switch always starts from the record. The original stays the record and is never modified.
- Claude (#1257) is untouched; claude at edit keeps naming the original and keeps its `--allowedTools=Read(//..)` grant. codex, opencode, agy yolo/harness: unchanged.

## Behaviour

1. At launch of a round whose candidate harness kind is `agy` and whose effective tier (`effectiveTier(b)`, which honours `b.RoundTier`) is `read` or `edit`, relevo (a) stages `<binding>/out/.NNN-prompt.md` with the exact bytes of `Store.PromptPath(binding, round)`, and (b) replaces the single `Read: <original>` line of the launch prompt with `Read: <copy>`. Nothing else in the text changes.
2. Any other kind or tier: no file is written, the text is untouched.
3. The copy is staged for local launches, served (server-side) launches, resume of a lost session, fresh relaunch after a daemon restart, candidate switch and account rotation of the same round, a repair round, and a chain member round: all of them pass through `startRound`/`resumeRound`.
4. `--dry-run` / preflight: the argv-building prompt in `pf.prompt` names the copy path when the rule applies, but nothing is written (read-only preflight).
5. The copy is removed when its round is sealed. It is never an artifact, never a round file, never sealed, listed, forked or migrated.
6. If staging fails (original unreadable, `out/` not a directory), the launch fails with the error; the round is not started with a prompt the runner cannot read.

## Seams

- `internal/harness/tier.go` (or `harness.go`): a pure `PromptCopyWanted(kind string, tier Tier) bool` -- true for kind `agy` and tier read or edit. One function, so the tier condition is stated once and mutation-testable.
- `internal/store/promptcopy.go` (new, < 100 lines): `PromptCopyPath(name string, round int) string` (= `OutDir/.NNN-prompt.md`), `StagePromptCopy(name string, round int, body []byte) (string, error)` (root-confined write as above), `removePromptCopy(root *os.Root, round int)`.
- `internal/store/seal.go` `SealRound` (~242-300): after the sealed files are removed and `removeEmptyRoundDirs(name, round)` runs, remove the round's prompt copy through the already-open `root`; error ignored apart from a slog warning, like the sealed-file removal.
- `internal/relevo/promptcopy.go` (new): `launchPrompt(rt Runtime, b store.Binding, kind string, tier harness.Tier, prompt string, stage bool) (string, error)` -- when `harness.PromptCopyWanted(kind, tier)`: copy path = `rt.Store.PromptCopyPath(b.Name, b.Round)`; replace the exact substring `"Read: " + original + "\n"` with the copy's once (`strings.Replace(..., 1)`); when `stage`, read the original with `rt.Store.ReadFile(original)` and call `StagePromptCopy` first. A prompt that does not contain the exact Read line is returned unchanged and, when `stage`, nothing is written (so a non-handoff prompt is never half-converted).
- `internal/relevo/headless.go`: `startRound` (~265-293): after `launchTier`, `prompt, err = launchPrompt(rt, b, c.Harness, tier, prompt, true)` before `HeadlessLaunch`. `resumeRound` (~440-488): same after `launchTier`, before `ResumeBuild`. Keep both under 70 lines (they are close; extract nothing else).
- `internal/relevo/send.go` `sendPreflight` (~425-440): `launchPrompt(..., pf.prompt-bearing text, stage=false)` using the local `tier` and candidate kind `c.Harness`; assign back to the prompt used for `HeadlessLaunch` and to `pf.prompt`. Check `send.go` stays <= 600 lines; if not, the call moves into the new relevo file.
- Not edited: `composePrompt`, `composeChainReaderPrompt`, `roundPrompt` (no signature churn; their many callers and tests keep working), `switch.go`, `queue.go`, `chain_send.go`, `repair.go`, `headless.go:1141` (they reach the hook through `startRound`/`resumeRound`).
- Docs: add one sentence to the place that describes agy tiers/the out/ layout if one exists (`grep -rn "accept-edits" docs README.md`); do not create a new doc. If none exists, skip.
