## Settled rules (each pinned by a named test)

**R1 — `text --json`.** One document on stdout, one line plus `\n`, `[]` (never `null`) when the scene has none:
`[{"id":"<id>","x":10,"y":20,"text":"hello"}]` — field order id, x, y, text (`board.TextElement`, `json.Encoder` default rendering). x/y marshal as float64 (`10`, `12.5`). Tests `TestTextJSONDocument`, `TestTextJSONEmptyIsEmptyArray`.

**R2 — `text` human.** One row per element through `tabwriter(w, 0, 0, 2, ' ', 0)`, no header: id, `strconv.FormatFloat(x,'f',-1,64)`, y, then the raw text cell (a multi-line text wraps; the JSON form is the lossless one). An empty scene prints nothing and exits 0. Test `TestTextHumanRows`.

**R3 — refusals.** `usage` (exit 2): no path or two positionals (`relevo board text needs one scene path`), a path not ending `.excalidraw` or outside the repo root, not inside a git repository, an unknown flag or flag value, `--text` absent (`--text is required`) or empty (`--text must not be empty`), exactly one of `--x`/`--y` (`--x and --y come together`), NaN/±Inf in either (`--x must be a finite number`). `refused` (exit 2, no `next`): a missing scene (`no scene at <path>`) and an invalid scene (the `board.ErrInvalid` text, e.g. `scene type is not "excalidraw"`). `internal` (exit 1): read and write failures. Every usage check runs before any cwd/repo/theme/file work. Tests `TestBoardTextRefusals`, `TestBoardAnnotateRefusals`.

**R4 — the element.** The appended JSON is exactly these 36 fields in this order (0.18.1's `newTextElement` + `_newElementBase`; its `customData` is `undefined`, so it is absent):
`{"id":<32 hex>,"type":"text","x":X,"y":Y,"width":W,"height":H,"angle":0,"strokeColor":"<theme ink>","backgroundColor":"transparent","fillStyle":"solid","strokeWidth":2,"strokeStyle":"solid","roughness":0,"opacity":100,"groupIds":[],"frameId":null,"index":null,"roundness":null,"seed":S,"version":1,"versionNonce":0,"isDeleted":false,"boundElements":null,"updated":U,"link":null,"locked":false,"text":"T","fontSize":20,"fontFamily":3,"textAlign":"left","verticalAlign":"top","containerId":null,"originalText":"T","autoResize":true,"lineHeight":1.2}`
`strokeColor` is the resolved theme's Ink (`boardResolveTheme(cwd, "")`: `relevo.boardTheme`, else cockpit), `roughness` the shared 0, `fontFamily` 3, `lineHeight` 1.2 (Cascadia's 0.18.1 metric), `fontSize` 20 (0.18.1's `DEFAULT_FONT_SIZE`). Every value is ours; a field a scene omits earns 0.18.1's restore default, never a second source. Tests `TestAnnotateElementFields` (the literal, fixed seams), `TestAnnotateStrokeIsThemeInk`.

**R5 — the random three.** Only `id` (16 random bytes hex), `seed` (random in [0, 2³¹)), `updated` (unix ms) are non-deterministic; they come from the package seams `newElementID`, `newElementSeed`, `elementNow` in `internal/board`, which board tests replace with fixed values and cmd tests only shape-check (`^[0-9a-f]{32}$`, seed in range, updated > 0). Test `TestAnnotateRandomFieldsAreWellFormed`.

**R6 — width/height.** Normalize first as 0.18.1 does (tab → 8 spaces; `\r\n`/`\r` → `\n`). `W = 12 × max line bytes` — 0.6em/rune with Cascadia's ~0.586em advance, and byte-counting over-counts every wider script, so the estimate errs upward; an empty line counts as one space, as 0.18.1's `measureText` does. `H = 24 × lines` (20 × 1.2). The emitted `width` is exactly the estimate and the test asserts `width ≥ estimateTextWidth(text)`, `autoResize == true`, `fontFamily == 3`. Tests `TestAnnotateWidthCoversTheEstimate`, `TestAnnotateEstimatePinsValues` ("hello" → 60×24; "hi\nthere" → 60×48).

**R7 — default position.** Over every non-deleted element, missing numeric fields = 0: `x = min(x)`, `y = max(y+height) + 20` (`annotateGap`, Excalidraw's DEFAULT_GRID_SIZE); no non-deleted element → `(0,0)`; deleted elements never move it. Tests `TestAnnotateDefaultPositionBelowBounds`, `TestAnnotateDefaultPositionEmptyScene`.

**R8 — byte stability.** Spliced, never unmarshalled/re-marshalled. The target is the last top-level `"elements"` key (the one encoding/json resolves when the name repeats), located with `json.Decoder`: `Decode(&raw)` then `end - len(raw)` recovers the value's exact start, so `,<element>` is inserted right after the last non-whitespace byte before the closing `]` (just `<element>` for an empty array). Every other byte keeps its position. Tests `TestAnnotateKeepsEveryOtherByte` (compact and pretty literals), `TestAnnotateRefusesMissingScene`.

**R9 — missing scene.** `annotate` refuses rather than creating one: S1's page owns "a missing file is a new scene", and the CLI would have to invent appState/files/version the spec does not pin, while a typo would leave a stray file. Both subverbs answer `refused`.

**R10 — cockpit.** `.excalidraw` opens `<name>.svg` beside it in the browser when that file exists, else it opens the `.excalidraw` in `$EDITOR`, and the tab shows the faint line `run relevo board <path> to edit` (`<path>` = the artifact's absolute path). OPENS IN and the open action share one decision function, so they cannot disagree; a sealed scene (not on disk) is the no-companion case, exactly as today. Test `TestArtifactsExcalidrawFallback` (both states).

**R11 — annotate output.** stdout is one line, `board: annotated <path> (id <id>)`, exit 0; there is no `--json` on annotate.

## Steps
