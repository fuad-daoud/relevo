# Plan T5: tmp-sweep

Part of the disk lane (#1314 runner temp dirs, #1308 Go build cache).

Depends on T2 and T3's key formats. It can run in parallel with T4 because it touches different files.

**Behaviour.**

The daemon removes leftovers under its `TmpRoot`. Serve runs the same sweep, because `internal/serve/daemon.go` ~43 `NewDaemon(runtimeAt(...))` per owner.

1. A `rounds/<name>-NNN` entry is removed unless its binding exists, is not DONE, and either:
   - the round number is the binding's current round and `store.RoundOpen` holds for it, or
   - the round number is greater than the current round. Send creates the dir before it logs the plan, and scratch has the same rule.

   Read a binding's log only for bindings that actually have a `rounds/` entry.
2. A `checks/<unit>` entry is removed unless its unit is in the open set:
   - a binding's `GateRun` (unit from `scopeUnitNameFor(scopeGate, owner, name, round, "")`);
   - an unsettled binding `CheckRun` (`servedCheckSpec(...)`'s unit);
   - an unsettled chain check row (`chainCheckSpec(...)`'s unit), for non-terminal chains, via `rt.Store.Chains()` and `ChainCheck`.

   An entry modified within the last 10 minutes is always kept, which covers the window between creating a dir and saving its row. A chain check that a stop or an abandon killed never passes `advanceGateProc`, so its `checks/<unit>` directory is left behind; the open set not holding it is what removes it (`TestSweepTmpRemovesCheckOfStoppedChain`).
3. Loose entries directly in `TmpRoot` are removed only when all of these hold:
   - It is a **directory**. Regular files are never touched. The root also holds live transport bundles, `req-body-*` and `plan-*` files, and Turso's `TURSO_TMPDIR`/`SQLITE_TMPDIR` files, because `prepareTempDir` points them at `<state root>/tmp`.
   - Its name is not `rounds` or `checks`.
   - The newest mtime among the directory and its direct children is at least 24 h old.
4. It never touches a path outside `TmpRoot`, the system `/tmp`, or an inherited `TMPDIR`. All removal goes through `os.Root` (T2's helpers), so a tenant-planted symlink is refused.

**Seams.**
- New `internal/relevo/tmpsweep.go`:
  - `SweepTmp(ctx, rt, bindings, now)` returns the removed paths. Per-entry errors are joined, and one bad entry never stops the rest.
  - Pure helpers for the open-set builder and the loose-age rule take `now` and mtimes as inputs, so the rules can be tested without a clock or a daemon.
- `internal/relevo/daemon.go`, `Tick` (~262): add `d.safely("tmp sweep", ...)` beside the scratch sweep, before the no-bindings early return. A `TmpRoot == ""` skips it.
- `docs/runbook.md`: one paragraph. The state tmp is now the default and is swept. Where an inherited `TMPDIR` drop-in is no longer needed, remove it by hand, with zen's `relevo-serve.service.d/tmpdir.conf` as the example. The directories `relevo-serve-tmp` and `relevo-serve-gotmp` are outside the root and are never swept. This is an ops step, not code.

**Steps.**
1. Write the pure rules and their tests.
2. Add the walk through `ListTmpEntries` and the removal.
3. Hook it into `Tick`. Deliverable: `go test ./internal/relevo/...` is green.
4. Add the runbook paragraph.

6. Save the plan to `docs/plans/2026-10-23-tmp-sweep.md` in the same commit.

**Tests.**
- `TestSweepTmpKeepsOpenRoundRemovesClosed`.
- `TestSweepTmpRemovesRoundOfDoneOrMissingBinding`.
- `TestSweepTmpKeepsRoundAheadOfCurrent`.
- `TestSweepTmpKeepsOpenChecksOfEachKind`.
- `TestSweepTmpKeepsFreshUnopenedCheck`: the 10-minute guard.
- `TestSweepTmpLooseOnlyOldDirectories`:
  - Old directories are removed.
  - Old regular files, including a file named like a bundle, are kept.
  - A directory with a fresh child is kept.
- `TestSweepTmpNeverTouchesOutsideRoot`: a symlink entry pointing outside is refused and its target survives.
- `TestSweepTmpOneFailureDoesNotStopOthers`.
- `TestSweepTmpRemovesCheckOfStoppedChain`: a `checks/<unit>` whose chain is stopped, so its unit is not in the open set, is removed.
- A Tick-level test for the hook and for the empty-root skip.

**Mutation targets.**
- Remove the `IsDir` filter: the keep-old-files test must fail.
- Set the age to 24 h minus 1 min, or ignore child mtimes: the fresh-child and age tests must fail.
- Drop the 10-minute guard: that test must fail.
- Swap `os.Root` for plain `os.RemoveAll`: the outside-root test must fail.

**Deleted.** None.

**Report must include.**
- What the builder found in a real `<state root>/tmp` on this machine (names only). Read-only, never deleted.
- The Turso temp file naming, if the builder could determine it.
- A residual-risk note: a directory a long-lived process holds open but has not modified for 24 h would be removed.
