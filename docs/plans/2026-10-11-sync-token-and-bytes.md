Cases: (a) neither route + stored token → enable proceeds (interrupted-join resume); (b) neither route + nothing stored → daemon usage refusal naming both routes (same text as today); (c) `--token-stdin`/env resolution order and fall-through unchanged (`enable.go:90-100`); (d) `--token-stdin` + `--r2-secret-stdin` still refused (`db_sync_r2.go:101-106`); (e) token never logged/printed (tail stays raw, `TokenPresent` bool only); (f) explicit-but-empty `--token-stdin` with nothing anywhere → daemon usage error (accepted asymmetry with R2's explicit-empty refusal, which stays).
