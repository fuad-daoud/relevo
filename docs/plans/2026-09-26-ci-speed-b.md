# CI speed B: fresh test databases come from a migrated template (2026-09-26)

## 1. System overview

Under `-race`, most test time goes to SQLite. modernc's SQLite is C transpiled to Go, so the race detector instruments
all of it.

The planner measured `db.Open` on a fresh file under `-race`:
- 55ms, against 2.3ms without race;
- about 10ms when the file is a copy of an already-migrated database, measured before the `have == know` fast path
  (commit dcf60d9); cheaper still with it.

Most tests in `internal/relevo`, `internal/stats`, `internal/ui`, `internal/config`, `internal/serve`,
`internal/store`, `internal/hooks` and `cmd/relevo` open one or more fresh databases.

This round adds a test-only seam to `internal/db`:
- A package's `TestMain` migrates one template database per test process.
- From then on, every `db.Open` on a path that does not exist yet starts from a byte copy of that template instead of
  running the migrations.
- Production never sets the template, so production behaviour is unchanged.

A database comes into existence only where production would create one, which is inside `Open`. So tests that assert
"a read creates no database" keep their meaning.

## 3. Data structures

- **Package state in `internal/db`:** one unexported `string` holding the template path. Empty means off.
  - It is written only by `SetFreshTemplate`, which is called from `TestMain` before `m.Run` or from a test that
    runs sequentially.
  - The goroutines of `m.Run` start after that write, so there is no race.
- **The template file:** a database created by `Open` on an empty temp path, then closed.
  - Closing must leave no `-wal` sibling with content. SQLite checkpoints on the last connection's close.
  - `dbtest` verifies this and fails loudly when a non-empty `-wal` remains, because a main file copied without its
    WAL would miss the schema.

## 4. Interfaces and contracts

### 4.1 `internal/db`

```
func SetFreshTemplate(path string)
```

- Sets or clears (with `""`) the template. The doc comment says what the name cannot:
  - it exists for tests;
  - relevo never calls it;
  - it must not be called while any goroutine may be inside `Open`.

```
func seedFromTemplate(path string)      // unexported; first statement of open, which Open delegates to
```

- It does nothing when:
  - the template is empty;
  - `os.Lstat(path)` returns anything other than `os.ErrNotExist` (the file exists, or the path cannot be inspected);
  - any step below fails. Seeding is best effort, and when it fails, `Open` migrates exactly as before.
- Otherwise it copies the template's bytes into a temp file in `filepath.Dir(path)` with mode `0600`, then publishes
  it with `os.Link(tmp, path)`.
  - The link is atomic, and it fails when `path` appeared in the meantime. A concurrent first open then simply uses
    the other file.
  - The temp file is always removed afterwards.
- Postcondition: `path` either did not change, or is a byte-identical copy of the template, published atomically.
- Everything after it in `Open` is unchanged: the ping, the `chmod`s, the version read, the fast path, and the
  migrations for an older file.

### 4.2 `internal/db/dbtest`

```
func Install() (cleanup func(), err error)
```

- `os.MkdirTemp` a directory, `db.Open` a file in it, and `Close` it. Fail if a `-wal` sibling with size > 0
  remains.
- Then `db.SetFreshTemplate(that file)`.
- `cleanup` clears the template (`SetFreshTemplate("")`) and removes the directory.

```
func Main(m *testing.M) int
```

- `Install`. On error, print it to stderr and return 1.
- Then `code := m.Run()`, `cleanup()`, and return `code`.
- Usage in each new `main_test.go`: `func TestMain(m *testing.M) { os.Exit(dbtest.Main(m)) }`.
- The package comment is one line saying what the package owns.

**`cmd/relevo/main_test.go`:** in the existing `TestMain`, call `dbtest.Install()` after `isolateTestEnv(root)` and
before `m.Run()`, and call the cleanup before `os.RemoveAll(root)`. On an Install error, `panic(err)`, as the
function already does for `MkdirTemp`.

## 5. Pseudocode

```
Open(path):
  seedFromTemplate(path)            # new, first
  ... unchanged ...

seedFromTemplate(path):
  tpl := template
  if tpl == "" : return
  if Lstat(path) err is not ErrNotExist : return
  tmp := CreateTemp(Dir(path), ".relevo-seed-*")      fail -> return
  copy bytes tpl -> tmp; Chmod 0600; Close            fail -> remove tmp; return
  Link(tmp, path)                                      fail (incl. exists) -> ignore
  Remove(tmp)
```

## 6. Error handling

- `seedFromTemplate` never returns an error and never logs. Every failure falls through to the migrating path that
  exists today.
- `dbtest.Install` returns every error. `Main` turns an error into exit code 1, with the message on stderr.
