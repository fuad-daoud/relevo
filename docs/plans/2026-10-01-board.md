# Plan: `relevo board` (#795), S1

The spec is `docs/specs/2026-10-01-board-design.md`. This plan is the S1 slice:
the cockpit `.svg` open kind plus the foreground `relevo board` with the
vendored Excalidraw page, one-scene GET/PUT, the companion `.svg`, the theme
table and defaults, and the README section. S1 is one builder round on one
branch and one commit series, and it opens the PR; the spec ships in it.

The seed and the issue text are in the spec; the builder reads the spec first.
`gh issue view 795` could not be read where this plan was written (the tree has
no git remote configured), so the issue body came from the MasterMind pasted
into the planning prompt. Any place the issue contradicts this plan, the
builder halts and reports rather than choosing.

## S1 steps

Each step names its deliverable and how to know it worked. Tests come first is
not required here, but every step's acceptance is a test or a command.

**S1.1 -- `internal/board/theme.go`.** The `Theme` type, the two built-ins, and
`Lookup(name)`. The theme drives the appState-defaults function from §8 of the
spec. Files: `internal/board/theme.go`, `internal/board/theme_test.go`.
Done when `theme_test.go` pins every hex value of both themes (all twenty values
plus Cascadia / fontFamily 3 / roughness 0) and `Lookup` refuses an unknown
name with a `usage` error that lists the valid names.

**S1.2 -- `internal/board/path.go`.** `Resolve(repoRoot, cwd, arg)`. The default
path is `docs/boards/board.excalidraw`; a path must end in `.excalidraw`, and
after `EvalSymlinks` on the deepest existing ancestor it must sit under
`repoRoot`. Files: `internal/board/path.go`, `internal/board/path_test.go`.
Done when the tests cover:
- the default path;
- a relative path;
- `..` escaping the root, refused;
- a symlinked parent pointing outside the root, refused;
- a wrong extension, refused;
- a missing file, accepted.

**S1.3 -- `internal/board/scene.go`.** Load, etag, validation and the atomic
save of scene plus svg. Files: `internal/board/scene.go`,
`internal/board/scene_test.go`. Done when the tests cover:
- an etag mismatch returns the conflict error;
- a crash before rename leaves the old file intact (no temp file is left behind
  on error);
- the svg is written next to the scene.

The etag is the sha256 of the scene bytes on disk. The save writes the scene to
a temp file in the same directory, renames it, then writes the svg the same way,
and returns the new etag.

**S1.4 -- `internal/board/server.go`.** The handler with the token, Host check,
caps, CSP and the three routes (§7 of the spec). Files:
`internal/board/server.go`, `internal/board/server_test.go`. Done when
`httptest` tests pin:
- 401 without the token and with a wrong one;
- 403 for a foreign Host;
- 413 and 422 for oversized and invalid bodies;
- 409 on a stale `If-Match`;
- 200 with a new etag;
- assets served without a token;
- `isNew` on a missing file.

The token is 32 random bytes in hex; the printed URL carries it in the fragment.
The constant-time compare is `crypto/subtle` (or `hmac.Equal`).

**S1.5 -- assets.** `internal/board/assets.go`, `internal/board/assets/`,
`board/`, `scripts/board-assets.sh`, the Makefile `board-assets` target (add it
to `.PHONY`, `Makefile:13`), and `.gitignore` gaining `board/node_modules/`.
The script does `npm ci`, the esbuild bundle, the copy of `dist/prod/index.css`
and of the `dist/prod/fonts/` tree, and writes `LICENSES.txt` and
`assets.sha256`. `internal/board` embeds `assets/` and `assets_test.go` checks
the manifest both ways: every embedded file is listed with a matching sha256,
and every listed file exists. Done when:
- `make board-assets` regenerates the assets byte-identically on a second run;
- `assets_test.go` passes;
- shellcheck is clean;
- `sh scripts/check-name.sh` passes, with finding A.4 applied only if needed
  (one `:(exclude)internal/board/assets/**` pathspec next to `go.sum`, and the
  report says it is a generated-file exemption, not a lint exclusion).

**S1.6 -- `cmd/relevo/board.go`.** `cmdBoard` and `boardFlagSet` (`--no-open`,
`--theme`), plus:
- the dispatch case and usage line in `cmd/relevo/main.go:203-250` and
  `:36-84`;
- `"board"` in `isPeekArgs` (`machinedb.go:122`);
- the registry entry in `registry_rows.go` (flags sorted; exit 0/1/2; errors
  `usage`, `internal`) and in `verbFlagSets` in `registry.go`.

The opener and listener are injectable, so tests never exec `xdg-open`. **The
`cmd/relevo` tests only parse and refuse**: no listen, no harness, no network,
per CLAUDE.md. Done when the registry tests (`registry_test.go:143-240`), a
route test like the bugreport one (`machinedb_routes_test.go:203-211`), and the
refusal tests (outside a repo, bad theme, bad path) pass.

**S1.7 -- Cockpit `.svg`.** `artifactOpenKind` at
`internal/ui/artifacts.go:29-38` maps `.svg` to `"browser"`, and
`artifacts_test.go:157-161` gains an `.svg` row. Done when that test passes.
Mutation: dropping the case makes it fail.

**S1.8 -- README.** A `### relevo board` section after `### relevo show`
(README:1113), plus a bullet in `## Command surface`. Done when the contract and
doc tests pass.

**S1.9 -- Coverage.** `internal/board` is a new package, so regenerate the
baseline with `sh scripts/check-coverage.sh --write` and say so in the report.
No existing line may drop.

**S1.10 -- Hand check, recorded in the report.** Run `relevo board` in this repo
and confirm each of:
- fonts load from `/assets` with no CDN request (devtools network tab);
- text drawn before and after a reload is not clipped;
- save writes both `.excalidraw` and `.svg`;
- an edit on disk while the page is open produces the 409 notice;
- Ctrl-C exits cleanly;
- the cockpit opens the `.svg` in the browser;
- finding A.5 holds (the canvas colour equals the stored colour).

**S1.11 -- Plan file.** Save the S1 plan as
`docs/plans/2026-10-01-board-s1.md` as the round's last commit.

## Mutations S1's report must show

Each fails a named test, then is reverted:

- drop the token compare (`server_test.go` 401 cases fail);
- drop the Host check (the 403 case fails);
- drop the `If-Match` check (the 409 case fails);
- make `Resolve` skip `EvalSymlinks` (the symlinked-parent case fails);
- change one theme hex (`theme_test.go` fails);
- remove one manifest line (`assets_test.go` fails).

## S2 and S3: outlines only

**S2.** `board text` and `board annotate` (subverb dispatch plus registry rows);
the font-safety test (the emitted element carries `autoResize:true`, an explicit
`width` ≥ the measured estimate, and `fontFamily` 3); the `.excalidraw` cockpit
fallback, which adds an open kind and a hint line (`"run relevo board <path> to
edit"`), choosing the companion `.svg` when it exists.

**S3.** The Mermaid render and import in the page; the recolouring by role
(node → panel/ink, edge → line, cluster → faint); `themeVariables` built from
the theme table; a regenerated asset manifest.
