## Exact shapes

```go
// internal/policy/policy.go
type ChainPolicy struct {
    MaxCorrections *int   `json:"max_corrections,omitempty"`
    ReviewerActor  string `json:"reviewer_actor,omitempty"`
    PlannerActor   string `json:"planner_actor,omitempty"`
    SecurityActor  string `json:"security_actor,omitempty"`
    Security       *bool  `json:"security,omitempty"`
}
// Policy gains: Chain *ChainPolicy `json:"chain,omitempty"`

const (
    DefaultChainMaxCorrections = 3
    DefaultChainReviewerActor  = "reviewer"
    DefaultChainPlannerActor   = "lite-planner"
    DefaultChainSecurityActor  = "security"
)

func (p Policy) ChainMaxCorrections() int      // nil-safe, default 3
func (p Policy) ChainReviewerActor() string    // "" -> "reviewer"
func (p Policy) ChainPlannerActor() string     // "" -> "lite-planner"
func (p Policy) ChainSecurityActor() string    // "" -> "security"
func (p Policy) ChainSecurityOn() bool         // nil -> false
```

- `validateChain`: `max_corrections >= 0`; a set actor name must be non-empty after trimming; errors
  wrap `ErrBadPolicy` with the style of `validateNotify` (`policy_test.go` pins the exact text).
- The five settings rows: keys `chain.max_corrections`, `chain.reviewer_actor`, `chain.planner_actor`,
  `chain.security_actor`, `chain.security`, group `chain`, form `chain`, `Set` from the raw `Chain`
  fields, value/default rendered through the accessors (`on`/`off` for security).
- `newChainFields`: two chips for `chain.security` (`off`/`on`) plus four text fields
  (`max_corrections` parsed as a non-negative int, three actors parsed as trimmed non-empty text),
  following the `newClassifyFields` shape (`internal/ui/settings_form_defs.go:95-146`).
