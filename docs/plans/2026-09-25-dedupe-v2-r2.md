# Mirror dedupe v2, round 2: a row with no record JSON is proven by the sealed builder.log, or carries nothing (#476)

## 1. System Overview

Round 1 (commit `d0b708e`, PR #481) implemented the round-1 plan exactly. Its
rule had a planner error. A dry run on a copy of the live database
(`TestDedupeMirrorRehearsal` with the four rename env vars) planned **0**
transcript rounds instead of the expected 127.

The cause is the rule the planner wrote for `streamLinesCover`, "a row with an
empty `RecordJSON` → not covered". The live mirror rounds hold three kinds of
row with an empty `RecordJSON`:

| kind | rows | rounds | in the sealed files? |
|---|---|---|---|
| empty `RecordJSON` **and** empty `Rendered` (a blank stream line) | 250 | 127 | carries nothing |
| empty `RecordJSON`, non-empty `Rendered` that is a line of the round's sealed `NNN-builder.log` (log-derived rows, mixed into 30 opencode rounds alongside stream rows) | about 5,300 | 30 | yes: `Rendered` is the log line verbatim (`logOnlyTranscriptRecords`, `internal/ingest/transcript.go:74`) |
| empty `RecordJSON`, `Rendered` **not** a line of `builder.log` | 22 | 21 | no, so keep |

The corrected rule, per row:

1. `RecordJSON != ""` → covered iff it is a line of the sealed
   `NNN-builder.jsonl`, directly or after `legacy.RewriteJSON(…, renames)`.
   Unchanged from round 1.
2. `RecordJSON == ""` and `Rendered == ""` → covered, since the row holds nothing.
3. `RecordJSON == ""` and `Rendered != ""` → covered iff `Rendered` is a line of
   the sealed `NNN-builder.log` (`builderLogPathBase`), split with the same
   `roundFileLines`. No rename rewrite: `relevo migrate` never rewrote `.log`
   files. Missing log file → not covered.

A round is planned when every row is covered. The planner re-ran the
measurement with this rule on the live data: **127 rounds and 31,749 rows
planned**, 21 rounds kept, 2 bindings unmapped.

Everything else from round 1 stays: the kv key, the stats fields, the legacy
helpers, the migrate refactor and the daemon wiring.

## 4. Interface Definitions & Component Contracts

`streamLinesCover(d, record, rd, rows, renames) (covered bool, renamed int, err error)`,
`internal/ingest/dedupe.go`, the function round 1 added after `planTranscript`.
Same signature and the same error wrapping.

- Load the stream set as today. A missing stream no longer returns early: a
  round whose rows are all case 2 or case 3 can still be covered without it.
  A row in case 1 with no stream → not covered.
- The log set is loaded only when a case-3 row is first met:
  `d.RoundFileGet(record.ID, builderLogPathBase(rd.Number))`, split with
  `roundFileLines`. A read error is wrapped as
  `dedupe: round file <name>/<base>: %w`, a split error as
  `dedupe: split <name>/<base>: %w`. Not found → the case-3 row is not covered.
- Apply the three cases of §1 to each row, in order. The first uncovered row
  returns `false, 0, nil`.
- Rewrite the doc comment to state the three cases, and why case 2 and case 3
  lose nothing (rendered log rows are the log line verbatim; a blank row holds
  nothing).

## 5. High-Level Pseudocode

```
streamLinesCover(...):
    stream = lines of NNN-builder.jsonl, or nil when absent
    log = not loaded
    for row in rows:
        if row.RecordJSON != "":
            if stream has it: continue
            if renames and rewritten != row.RecordJSON and stream has rewritten: renamed++; continue
            return false
        if row.Rendered == "": continue
        if log not loaded: log = lines of NNN-builder.log, or nil when absent
        if log has row.Rendered: continue
        return false
    return true, renamed
```

## 6. Error Handling Strategy

Unchanged: file read and split errors fail the plan (the daemon logs "mirror
dedupe skipped" and retries at the next start). Every other outcome is "kept".
